# Проверяй ИИ — сайт с результатами тестов
Готовый чёрно-белый многостраничный портал с фотографией. Загрузите всё содержимое этой папки в корень NormalQI/proveryai-ai: все HTML, style.css, script.js, config.js, favicon.svg, .nojekyll и папку assets.
GoatCounter настроен на публичный код proveryai-ai. Для результатов в Google Таблице заполните resultsEndpoint в config.js. Полная инструкция и Code.gs находятся в отдельной папке google-results комплекта. Эту отдельную папку на GitHub загружать не нужно.
Посетитель добровольно отправляет результаты кнопкой после теста. Без подключения таблицы кнопка скрыта. Имя и email не запрашиваются. Проверены синтаксис, валидация и подсчёт баллов на сервере, завершение теста в браузере без приёмника. Реальное сохранение требует развёртывания в аккаунте владельца и проверки по инструкции.
