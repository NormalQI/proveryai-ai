# Проверяй ИИ — обновлённый портал

Готовый статический сайт для https://normalqi.github.io/proveryai-ai/ . Без сборки и зависимостей. Сохранены название, цель и образовательное направление исходного index.html из публичного репозитория NormalQI/proveryai-ai. Исходные CSS и JS не переносились: интерфейс и интерактивные разделы переработаны.

## Что внутри
Тёмный адаптивный дизайн, мягкая анимация с учётом reduced-motion, разделы проекта и команды, польза и риски, семь шагов проверки с локальным сохранением, три теста по четыре вопроса с объяснениями, скачивание памятки, место для исследования без выдуманных результатов. Персональные данные и ответы не собираются. Имена команды не предоставлены — стоит честная заглушка.

## Замена файлов на GitHub
1. Распакуйте ZIP. Файлы сайта лежат прямо в корне архива; распакуйте их в отдельную папку proveryai-ai.
2. Откройте https://github.com/NormalQI/proveryai-ai и выберите ветку, из которой уже публикуется сайт (обычно main). Сохраните резервную копию: Code → Download ZIP.
3. Add file → Upload files. Перетащите СОДЕРЖИМОЕ папки proveryai-ai в корень репозитория, рядом с существующим index.html. Не загружайте сам ZIP и не создавайте вложенную папку proveryai-ai/proveryai-ai.
4. Загрузите index.html, style.css, script.js, config.js, favicon.svg, README.md и скрытый файл .nojekyll. Если скрытый файл не виден, создайте его через Add file → Create new file. Он пустой.
5. Нажмите Commit changes. Существующие одноимённые файлы будут заменены. Старые файлы с другими именами можно оставить до проверки, но проверьте, что в них нет личных данных.
6. Settings → Pages: если сайт уже работает, сохраните текущий источник публикации. Для обычной публикации из ветки: Deploy from a branch → main → /(root). Если настроен GitHub Actions, сохраните его или осознанно переключите на ветку.
7. Дождитесь успешного Pages build в Actions, затем откройте https://normalqi.github.io/proveryai-ai/ и обновите страницу с очисткой кэша (Ctrl+F5).
8. Проверьте меню на телефоне, чек-лист, все три теста и скачивание памятки. Публикация из этого архива автоматически не выполнялась.

## Аналитика и публичный счётчик: GoatCounter
Готов код подключения, но по умолчанию он ВЫКЛЮЧЕН: чужой счётчик и вымышленные цифры не используются. Создание аккаунта выполняет владелец. Не нужны платный сервер и секреты в клиентском коде. Условия и доступность тарифа проверьте при регистрации.

1. Откройте https://www.goatcounter.com/ и создайте свой счётчик для сайта. Укажите адрес https://normalqi.github.io/proveryai-ai/ . Подтвердите аккаунт, если сервис попросит.
2. Получите поддомен из выданного адреса: для https://my-project.goatcounter.com/count значение — my-project.
3. Откройте config.js и замените пустую строку: window.PORTAL_CONFIG = { goatcounterCode: 'my-project' }; Используйте именно СВОЙ код. Это публичный идентификатор, а не пароль. API-токены не вставляйте.
4. В настройках сайта GoatCounter включите «Allow adding visitor counts on your website», если хотите видеть число на самом портале. Полную панель аналитики можно оставить закрытой. Документация: https://www.goatcounter.com/help/visitor-counter .
5. Загрузите изменённый config.js на GitHub и откройте опубликованный сайт. Код работает только на normalqi.github.io, чтобы локальные проверки не засоряли статистику. При смене домена обновите проверку hostname в script.js.
6. Откройте сайт из обычного браузера без блокировщика и проверьте появление просмотра в панели GoatCounter. Учитывается единый путь /proveryai-ai/ — параметры UTM и якоря не создают отдельные страницы. Код не передаёт referrer.
7. После появления первой записи проверьте число в подвале. При запрете публичного счётчика, блокировщике, отсутствии данных или недоступности сервиса сайт показывает понятный статус. Показанное число может обновиться с задержкой; оно запрашивается при открытии страницы, а не в реальном времени.

Это число просмотров страницы, НЕ число уникальных людей и не результаты анкетирования. Часть посещений может блокироваться или отфильтровываться. Не используйте localStorage как общий счётчик: он отражает только один браузер. Секретный API для этой реализации не используется. Настройки сбора, сроки хранения и требования к уведомлению посетителей выбирает владелец под свою аудиторию; краткое уведомление в подвале уже есть.

Официальные инструкции: https://www.goatcounter.com/help/start , https://www.goatcounter.com/help/path , https://www.goatcounter.com/help/privacy . Чтобы отключить аналитику, верните пустую строку в config.js. Автоматический подсчёт без создания счётчика не обещается.

## Где менять содержимое
- index.html: тексты, участники (#team), исследование (#research). Имена добавляйте только после подтверждения. Для результатов укажите сроки, метод набора, размер выборки, вопросы, числа и ограничения; не публикуйте персональные ответы. Сейчас формы сбора нет.
- script.js: шаги проверки и массив quizzes. Индекс правильного ответа начинается с 0. Тесты учебные, не диагностические; ответы в открытом JS видны всем.
- style.css: цвета и оформление. Используются системные шрифты, внешние шрифты и картинки не загружаются.
- config.js: только публичный код GoatCounter.

## Проверка локально
Откройте index.html для чтения или используйте любой локальный статический HTTP-сервер (например npx --yes serve . при установленном Node.js). Интернет для основных функций не нужен. На локальном адресе аналитика отключена. Если браузер запрещает локальное хранилище, чек-лист работает без сохранения.

## Ограничения
Реальные результаты анкетирования и состав команды не предоставлены. Аналитика требует настройки владельцем и проверки на опубликованном домене. Никаких секретов и внешней базы данных в архиве нет. Ссылки на ЮНЕСКО и NIST — материалы для дальнейшего изучения, а не подтверждение каждой фразы портала.
