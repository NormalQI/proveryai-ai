ПРОВЕРЯЙ ИИ — ИНСТРУКЦИЯ

Состав папки:
- index.html — страница сайта
- style.css — внешний вид
- script.js — интерактивный чек-лист и тест

1. ОТКРЫТЬ НА WINDOWS
Распакуйте ZIP-архив. Откройте папку proveryai-ai и дважды нажмите index.html.
Сайт откроется в браузере. Для локального запуска сервер и интернет не нужны.
Проверьте вкладку «Чек-лист» (отметки и сброс) и вкладку «Тест» (5 вопросов).

2. ОПУБЛИКОВАТЬ БЕСПЛАТНО В ИНТЕРНЕТЕ
- Зарегистрируйтесь на github.com.
- Создайте публичный репозиторий, например proveryai-ai.
- Загрузите в корень репозитория index.html, style.css и script.js.
- Settings -> Pages -> Build and deployment -> Deploy from a branch.
- Выберите main и / (root), нажмите Save.
- После публикации ссылка будет иметь вид https://ИМЯ.github.io/proveryai-ai/
Публикация может занять некоторое время.

3. СВОЙ ДОМЕН
Купите свободный домен у регистратора и подключите через Settings -> Pages -> Custom domain.
DNS-записи настраиваются по инструкции GitHub Pages и вашего регистратора.

4. ИЗМЕНЕНИЯ
Тексты и блоки редактируются в index.html, оформление — в style.css,
вопросы теста и чек-лист — в script.js.

Это статический учебный сайт. Данные чек-листа и теста не отправляются на сервер
и при перезагрузке страницы сбрасываются.
